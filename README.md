# KO_OP Utils

Shared utility and helper functionalty for KO_OP Unity projects.

To install KO_OP Utils, use the Package Manager to install each of its dependencies, followed by the package itself:

1. Use the Package Manager to install the Localization package from the Unity Registry.
2. Use the Package Manager to install `com.unity.settings-manager` at version `2.1` using the `Install package by name...` option
3. Use the Package Manager to install each of the following packages in order, using the `Install package from git URL...` option:

```
https://github.com/Cysharp/UniTask.git?path=src/UniTask/Assets/Plugins/UniTask
https://github.com/jonagill/UnityCollections.git?path=Packages/com.jonagill.unitycollections
https://github.com/jonagill/UnityInternalAccess.git?path=Packages/com.jonagill.unityinternalaccess
https://github.com/jonagill/BulkEditor.git?path=Packages/com.jonagill.bulkeditor
https://github.com/KO-OPMode/KO-OPUtils.git
```
