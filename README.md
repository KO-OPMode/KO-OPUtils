# KO_OP Utils

Shared utility and helper functionalty for KO_OP Unity projects.

To install, first install Unity's Localization package via the Package Manager.

Then use the Package Manager to add the following packages via git URL:

```
https://github.com/Cysharp/UniTask.git?path=src/UniTask/Assets/Plugins/UniTask
https://github.com/jonagill/UnityCollections.git?path=Packages/com.jonagill.unitycollections
https://github.com/jonagill/UnityInternalAccess.git?path=Packages/com.jonagill.unityinternalaccess
https://github.com/jonagill/BulkEditor.git?path=Packages/com.jonagill.bulkeditor
https://github.com/KO-OPMode/KO-OPUtils.git
```
